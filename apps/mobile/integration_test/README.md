# Integration tests

`release_scope_screenshots_test.dart` drives the real app on a device against the captured API
fixtures and saves the screenshots of RELEASE_SCOPE.md §2.6/§4 under `docs/screenshots/core/`.

`minimal_core_screenshots_test.dart` does the same for the minimal `core` app of RELEASE_SCOPE.md
§4.1 (home as issuer and as participant, My competitions, the Account hub, Notifications,
Competitions, and the `full` home and hub for comparison) under `docs/screenshots/minimal/`
(screenshot names `minimal/<file>`; the driver writes `<dir>/<file>` names under that directory).

```sh
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
~/Library/Android/sdk/emulator/emulator -avd Pixel_API34 -no-window -no-audio -no-boot-anim &
flutter drive --driver=test_driver/integration_test.dart \
  --target=integration_test/release_scope_screenshots_test.dart -d emulator-5554
flutter drive --driver=test_driver/integration_test.dart \
  --target=integration_test/minimal_core_screenshots_test.dart -d emulator-5554
```

`fixtures.g.dart` embeds the fixtures the run needs (a device cannot read the repository).
Regenerate it after a fixture changes:

```sh
python3 - <<'PY'
import json
names=['app_config','time','me_issuer','home_issuer','notifications_unread_count','competitions_issuer','lookups',
       'auth_login_supplier_a','home_supplier_a','competitions_participant_a','notifications_issuer','notifications_supplier_a']
out=["// GENERATED by the release-scope screenshot run: the captured API fixtures",
     "// of test/fixtures/api that the integration test serves on the device (a",
     "// device cannot read the repository's files). Regenerate with the Python",
     "// snippet in integration_test/README.md.","",
     "/// Raw `{status, body}` envelopes by fixture name.",
     "const Map<String, String> embeddedFixtures = {"]
for n in names:
    compact=json.dumps(json.load(open(f'test/fixtures/api/{n}.json',encoding='utf-8')),ensure_ascii=False,separators=(',',':'))
    esc=compact.replace('\\','\\\\').replace("'","\\'").replace('$','\\$')
    out.append(f"  '{n}':\n      '{esc}',")
out.append("};")
open('integration_test/fixtures.g.dart','w',encoding='utf-8').write("\n".join(out)+"\n")
PY
dart format integration_test/fixtures.g.dart
```
